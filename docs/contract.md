# Internal integration contract

All JSON uses snake_case. Musical times are milliseconds as f64 at original tempo. Transport speed scales wall time, never pitches. IDs are stable within a parsed file; library IDs are SHA-256 of exact source bytes.

`model.rs`: serde Serialize/Deserialize models. `Song { ppq: u16, duration_ms: f64, notes: Vec<Note>, parts: Vec<Part>, tempos: Vec<Tempo>, time_signatures: Vec<TimeSignature>, controllers: Vec<Controller>, warnings: Vec<String> }`. `Note { id:u32, part_id:u32, channel:u8, pitch:u8, velocity:u8, start_tick:u64, end_tick:u64, start_ms:f64, end_ms:f64 }`. `Part { id:u32, track:u32, channel:u8, name:String, note_count:usize, percussion:bool }`. `Tempo { tick:u64, micros_per_quarter:u32, time_ms:f64 }`. `TimeSignature { tick:u64, numerator:u8, denominator:u16 }`. `Controller { part_id:u32, channel:u8, tick:u64, time_ms:f64, controller:u8, value:u8 }`.

`SongSettings { speed:f64, mode:String, parts:Vec<PartSetting>, loop_start_ms:Option<f64>, loop_end_ms:Option<f64>, position_ms:f64, split_pitch:Option<u8>, count_in:bool, metronome:bool }` with Default. `PartSetting { part_id:u32, role:String, hand:String, volume:f32, solo:bool }` with role practice/accompaniment/muted; hand left/right/auto. Missing part settings mean practice unless percussion (accompaniment).

`parser::parse(bytes:&[u8]) -> Result<Song,String>` bounded and never panics on malformed input.

`library::Library::open(root:PathBuf) -> Result<Self,String>`; `import_path(&mut self,path:&Path)->Result<ImportResult,String>`; `list(&self,query:&str,favorites:bool)->Result<Vec<LibraryEntry>,String>`; `load(&self,id:&str)->Result<Song,String>`; `settings(&self,id:&str)->Result<SongSettings,String>`; `save_settings(&mut self,id:&str,settings:&SongSettings)->Result<(),String>`; `update_metadata(&mut self,entry:&LibraryEntry)->Result<(),String>`; `mark_played(&mut self,id:&str)->Result<(),String>`; `remove(&mut self,id:&str)->Result<(),String>` deletes managed only; `export(&self,id:&str,destination:&Path)->Result<(),String>`. `LibraryEntry { id:String,title:String,artist:String,tags:String,arrangement:String,favorite:bool,imported_at:i64,last_played:Option<i64>,duration_ms:f64,parts_count:usize,note_count:usize }`. `ImportResult { entry:LibraryEntry, duplicate:bool, elapsed_ms:f64 }`. Per-file errors do not abort batches. Keep `.part` files non-ready, recovery removes incomplete copies.

`transport::Engine`: `new()`, `load(song:Song,settings:SongSettings)`, `play()`, `pause()`, `stop()`, `seek(ms:f64)`, `configure(settings:SongSettings)`, `advance(elapsed_ms:f64)->Vec<VoiceEvent>`, `input(pitch:u8,on:bool,velocity:u8,source:InputSource)`, `snapshot()->TransportSnapshot`, `drain_events()->Vec<VoiceEvent>` (commands/input may queue reset events). `InputSource { Physical, Simulated, Playback }`. `VoiceEvent { On { key:u32,pitch:u8,velocity:u8,volume:f32 }, Off { key:u32 }, Reset, Click }`. Engine is single-thread-owned; caller uses monotonic Instant deltas. `TransportSnapshot { position_ms:f64,duration_ms:f64,playing:bool,waiting:bool,mode:String,speed:f64,targets:Vec<u8>,matched:Vec<u8>,correct:u32,wrong:u32,missed:u32,feedback:String,beat:u32,count_in_remaining:u8 }`. Default or constructor required. `snapshot()` called at 30 Hz. Pure engine tests inject deltas.

Frontend IPC (lead implements): `library_list { query,favorites }`, `import_files { paths } -> Vec<{path,result?:ImportResult,error?:string}>`, `import_dialog` same result, `open_song { id } -> {entry,song,settings}`, `save_metadata { entry }`, `save_settings { id,settings }`, `remove_song { id,confirmed }`, `export_song { id }`, `devices -> Vec<{id,name}>`, `connect_device { id: string|null }`, `control { action:play|pause|stop|seek|panic|configure, position_ms?:number, settings?:SongSettings }`, `input_note {pitch,on,velocity}`, `preferences { value?:Preferences } -> Preferences`, `status -> AppStatus`, `demo_import -> ImportResult`, `take_pending_files -> string[]`.

`Preferences { device_id:string|null,monitor:string (yamaha|software),simulated:bool,low:u8,high:u8,labels:bool,note_numbers:bool }`. `AppStatus { transport:TransportSnapshot, device_id:string|null,device_name:string|null,device_connected:bool,audio_available:bool,audio_error:string|null,events:Vec<{sequence:number,source:string,kind:string,channel:u8,pitch:u8,velocity:u8}>,held:Vec<u8>,dropped_events:u64 }`. Frontend polls status at 30 Hz only while visible. Tauri `files-opened` event asks frontend to consume pending files; drag via window `onDragDropEvent`. Use regular browser preview only if visibly labeled disconnected preview, never as native proof.
