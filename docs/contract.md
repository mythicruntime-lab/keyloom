# Internal integration contract

All JSON uses snake_case. Musical times are milliseconds as f64 at original tempo. Transport speed scales wall time, never pitches. IDs are stable within a parsed file; library IDs are SHA-256 of exact source bytes.

## Preview tools (0.4.0)

`LessonToolRequest` is a snake_case tagged enum with unknown fields refused: `{ kind:"thin", strategy:"highest"|"bass_highest"|"limit", max_notes:u8, part_id:u32|null }` or `{ kind:"shift", note_ids:u32[], semitones:i16 }`. `max_notes` must be 1–8 for every thin request and controls the retained count only for `limit`. Shift accepts only −12 or +12; existing immediate pitch IPC remains available separately. `LessonPreview { revision:u64, changes:NoteChange[] }`; `NoteChange { note_id:u32, from_pitch:u8, to_pitch:u8|null }`, where null means removal. Changes are returned in ascending stable note-ID order.

`preview_lesson_tool { id,expected_revision,request } -> LessonPreview` reads one saved practice-version revision without writing notes, history or settings. `apply_lesson_tool { id,expected_revision,request } -> OpenSong` recomputes the request against that revision, saves one validated removal/pitch Undo batch and returns the reloaded version paused. Client-supplied change arrays are never applied. Original IDs, stale revisions, invalid selections and MIDI-overflow moves are refused; applying no changes does not create a history entry. Cancel is client-only disposal of the preview. These commands use schema-3 state and the existing 100-action/200,000-note-change history bounds.

Thin groups use exact `start_tick` and current surviving pitches. Null `part_id` combines all nonpercussion parts at each onset; a supplied ID scopes to that nonpercussion part. `highest` retains one highest event; `bass_highest` retains one lowest and one highest distinct pitch (one event for a unison); `limit` retains the highest `max_notes` note events, N=1–8, counting duplicate-pitch events separately. Equal-pitch ties retain lower stable IDs. Playback roles/Solo/split/loops do not change this editor scope. Whole-song range selectors operate on current nonpercussion notes and use `< low`, `> high` or their union; endpoints are in range. They replace selected IDs across the lesson rather than only the current page/filter.

The UI renders every returned change in pages of 48 and constructs an unsaved After roll from it; Before retains saved note data. After is the default. Immediate edits, Undo and export are blocked until Apply/Cancel; option, selection/range, version, navigation and revision changes invalidate the preview. Applying clears selection after acknowledgement. Preview never feeds the input matcher or loads an audition into the transport. Release verification belongs in the test report; this contract does not assert hardware acceptance.

## Practice versions and export (0.3.0)

`LibraryEntry` also includes `original_id:Option<String>` (missing means an original). Version IDs are `variant-<number>` and point directly to a root original. `OpenSong { entry,song,settings,lesson:Option<LessonState> }`; `LessonState { revision:u64,can_undo:bool,removed_count:usize,shifted_count:usize }`, with missing shifted count defaulting to zero.

IPC `create_variant { id,title }`, `remove_notes { id,expected_revision,note_ids }`, `transpose_notes { id,expected_revision,note_ids,semitones }` and `undo_notes { id,expected_revision }` return the reloaded `OpenSong`, paused. `lesson_versions { id }` returns the root and its versions. Transpose accepts only −12, −1, +1, +12; invalid batches are rejected atomically. Undo handles removals and pitches in reverse saved order.

`export_song { id } -> string|null` returns the new destination path, or null after dialog cancellation. Originals export exact bytes; versions export verified edited MIDI. Neither path overwrites a file. `exporter::edited_midi(original_bytes:&[u8],edited:&Song)->Result<Vec<u8>,String>` is byte-only and performs no file or device I/O. It checks the reparsed musical result before the library creates any destination. Practice speed/roles/loops are not exported.

`model.rs`: serde Serialize/Deserialize models. `Song { ppq: u16, duration_ms: f64, notes: Vec<Note>, parts: Vec<Part>, tempos: Vec<Tempo>, time_signatures: Vec<TimeSignature>, controllers: Vec<Controller>, warnings: Vec<String> }`. `Note { id:u32, part_id:u32, channel:u8, pitch:u8, velocity:u8, start_tick:u64, end_tick:u64, start_ms:f64, end_ms:f64 }`. `Part { id:u32, track:u32, channel:u8, name:String, note_count:usize, percussion:bool }`. `Tempo { tick:u64, micros_per_quarter:u32, time_ms:f64 }`. `TimeSignature { tick:u64, numerator:u8, denominator:u16 }`. `Controller { part_id:u32, channel:u8, tick:u64, time_ms:f64, controller:u8, value:u8 }`.

`SongSettings { speed:f64, mode:String, parts:Vec<PartSetting>, loop_start_ms:Option<f64>, loop_end_ms:Option<f64>, position_ms:f64, split_pitch:Option<u8>, split_hand:String (both|left|right, default both), count_in:bool, metronome:bool }` with Default. `PartSetting { part_id:u32, role:String, hand:String, volume:f32, solo:bool }` with role practice/accompaniment/muted; hand left/right/auto. Missing part settings mean practice unless percussion (accompaniment).

`parser::parse(bytes:&[u8]) -> Result<Song,String>` bounded and never panics on malformed input.

`library::Library::open(root:PathBuf) -> Result<Self,String>`; `import_path(&mut self,path:&Path)->Result<ImportResult,String>`; `list(&self,query:&str,favorites:bool)->Result<Vec<LibraryEntry>,String>`; `load(&self,id:&str)->Result<Song,String>`; `settings(&self,id:&str)->Result<SongSettings,String>`; `save_settings(&mut self,id:&str,settings:&SongSettings)->Result<(),String>`; `update_metadata(&mut self,entry:&LibraryEntry)->Result<(),String>`; `mark_played(&mut self,id:&str)->Result<(),String>`; `remove(&mut self,id:&str)->Result<(),String>` deletes managed only; `export(&self,id:&str,destination:&Path)->Result<(),String>`. `LibraryEntry { id:String,title:String,artist:String,tags:String,arrangement:String,favorite:bool,imported_at:i64,last_played:Option<i64>,duration_ms:f64,parts_count:usize,note_count:usize }`. `ImportResult { entry:LibraryEntry, duplicate:bool, elapsed_ms:f64 }`. Per-file errors do not abort batches. Keep `.part` files non-ready, recovery removes incomplete copies.

`transport::Engine`: `new()`, `load(song:Song,settings:SongSettings)`, `play()`, `pause()`, `stop()`, `seek(ms:f64)`, `configure(settings:SongSettings)`, `advance(elapsed_ms:f64)->Vec<VoiceEvent>`, `input(pitch:u8,on:bool,velocity:u8,source:InputSource)`, `snapshot()->TransportSnapshot`, `drain_events()->Vec<VoiceEvent>` (commands/input may queue reset events). `InputSource { Physical, Simulated, Playback }`; only Physical can match. `guide_targets()->Option<(u64,Vec<u8>)>` exposes eligible target chord plus occurrence identity. `VoiceEvent { On { key:u32,pitch:u8,velocity:u8,volume:f32 }, Off { key:u32 }, Reset, Click }`. Engine is single-thread-owned; caller uses monotonic Instant deltas. `TransportSnapshot { position_ms:f64,duration_ms:f64,playing:bool,waiting:bool,mode:String,speed:f64,targets:Vec<u8>,matched:Vec<u8>,correct:u32,wrong:u32,missed:u32,feedback:String,beat:u32,count_in_remaining:u8 }`. Default or constructor required. `snapshot()` called at 30 Hz. Pure engine tests inject deltas.

Frontend IPC (lead implements): `library_list { query,favorites }`, `import_files { paths } -> Vec<{path,result?:ImportResult,error?:string}>`, `import_dialog` same result, `open_song { id } -> {entry,song,settings}`, `save_metadata { entry }`, `save_settings { id,settings }`, `remove_song { id,confirmed }`, `export_song { id }`, `devices -> Vec<{id,name}>`, `connect_device { id: string|null }`, `output_devices -> Vec<{id,name}>`, `connect_output {id:string|null}`, `test_light` (two-second MIDI note 60), `control { action:play|pause|stop|seek|panic|configure, position_ms?:number, settings?:SongSettings }`, `input_note {pitch,on,velocity}`, `preferences { value?:Preferences } -> Preferences`, `status -> AppStatus`, `demo_import -> ImportResult`, `take_pending_files -> string[]`.

`Preferences { device_id:string|null,output_device_id:string|null,light_guide:bool (default false),monitor:string (yamaha|software),simulated:bool,low:u8,high:u8,labels:bool,note_numbers:bool }`. `AppStatus { transport:TransportSnapshot, device_id:string|null,device_name:string|null,device_connected:bool,audio_available:bool,audio_error:string|null,events:Vec<{sequence:number,source:string,kind:string,channel:u8,pitch:u8,velocity:u8}>,held:Vec<u8>,dropped_events:u64 }`. Frontend polls status at 30 Hz only while visible. Tauri `files-opened` event asks frontend to consume pending files; drag via window `onDragDropEvent`. Use regular browser preview only if visibly labeled disconnected preview, never as native proof.

Light Guide AppStatus fields: output_device_id/output_device_name/output_error nullable strings; output_connected, light_guide, light_test_active booleans; lit_notes:number[] (sent/possibly active, not optical confirmation); output_messages:number counts successful sends. Preferences are acknowledged by the worker before persistence. Only output connection commands own the saved output ID.
